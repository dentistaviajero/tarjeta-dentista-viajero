# Tarjeta Digital | Dentista Viajero
Sitio estático listo para GitHub Pages. Todos los archivos, incluidas las imágenes `.webp`, se suben **directamente a la raíz** de la rama `main`. No necesitas crear una carpeta assets.

## Instalación
1. Descomprime el ZIP.
2. Sube **todos los archivos** a la raíz de `main`, sustituyendo `index.html`, `styles.css`, `app.js` y `config.js` anteriores.
3. En GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Visita https://dentistaviajero.github.io/tarjeta-dentista-viajero/

## Importante
- Las ocho tarjetas de servicios son imágenes recortadas de la ilustración aprobada y son botones navegables.
- `portada-personajes.webp` es una imagen de la combi y personajes; no es un enlace.
- Para activar WhatsApp, reservas y redes sociales, edita `config.js` con enlaces confirmados.
- No introduzcas datos de pacientes ni secretos en este repositorio público.
- GitHub distingue mayúsculas y minúsculas en nombres de archivo.
